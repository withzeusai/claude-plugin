# Hercules

Hercules is an AI app builder. Chat with AI to build production-ready, full-stack web applications — SaaS tools, CRMs, ERPs, ecommerce sites, landing pages, blogs, and more. No technical skills required.

Everything you need is built in: backend, database, hosting, auth, domains, payments, email, analytics, version control, AI, and 3rd-party connectors. Apps scale to millions of users.

This plugin connects Claude Code to the Hercules MCP server so you can build and manage Hercules apps directly from Claude.

## Installation

In Claude Code, run:

```
/plugin install hercules
```

Or, to install directly from this repository:

```
/plugin marketplace add <owner>/<repo>
/plugin install hercules
```

## Authentication

The first tool call prompts you to connect via OAuth in your browser. There are no API keys to generate, copy, or rotate.
